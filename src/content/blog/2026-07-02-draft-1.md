Ive been reading Learning Systems thinking by 
Diana Montalion. I started reading it on my flight from lisbon, portugal to london stanstead.
The book is about how to become a systems thinker. It starts with what is system thinking in the first place. 
It compares linear thinking to non linear thinking and then classifies ststems thinking as non linear. humans can naturally think in linear terms, so when someone thinks non linearly, people find it absurd or unbelievable. But we need systems thinking because some systems are complex
and linear thinking wont be able to simplify, optimize these systems. there are leverage points that can be used to get asymmetric results.
